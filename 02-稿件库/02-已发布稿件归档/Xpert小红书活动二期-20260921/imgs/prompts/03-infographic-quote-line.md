Create a Xiaohongshu (Little Red Book) style infographic following these specifications.

TYPE: Infographic — quote card
ASPECT: 3:4 portrait (vertical), 2k quality

## Core Principles

- Clean composition with generous white space (about 70%). Simple background. Single focal point centered.
- Hand-drawn quality throughout — diagram-style visuals ONLY, NO realistic or photographic elements.
- Color values and color names are rendering guidance only — do NOT display color names, hex codes, or palette labels as visible text in the image.

## Text Style (CRITICAL)

- ALL text MUST be hand-drawn hand-lettered style. The main quote must be very large, bold and eye-catching. NO computer-generated fonts.

## Language

- All text in Simplified Chinese, except the brand name "Xpert" which must be spelled exactly as "Xpert" in Latin letters.

## Palette (notion, default)

- Background: pure white / off-white
- Ink: black and dark gray for ALL lines, text, doodles
- Accents: light pastel yellow highlighter swipe only (never render color names or codes as text)
- Style: simple line doodles with slight hand-drawn wobble, single-weight ink lines, clean uncluttered notion knowledge-card look

## Layout (Sparse quote card)

- Single focal point centered, breathing room on all sides
- Nothing critical in the bottom 10% zone or top-right corner

## Content (LABELS — render ONLY these three text elements, nothing else)

1. Small handwritten label at the top:
   「Xpert 做任务手记」
2. Main quote, very large bold hand-lettered Chinese, centered:
   「认真只是及格线」
3. Secondary line below it, smaller:
   「专业，是把好东西讲清楚为什么好」

## Visual Concept

- A soft pastel yellow highlighter swipe behind 「及格线」
- A tiny hand-drawn stick figure climbing stairs doodle at the bottom-left, subtle
- A few hand-drawn sparkles scattered sparsely

## Absolute Prohibitions

- Render ONLY the exact text listed above — absolutely NO other characters, letters, numbers, symbols, watermarks, color codes, or gibberish text anywhere
- NO currency symbols, NO money amounts, NO QR codes, NO logos, NO URLs
- NO recruitment wording such as 报名, 加群, 私信
- Do not distort or drop any Chinese character
