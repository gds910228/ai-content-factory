Create a Xiaohongshu (Little Red Book) style infographic following these specifications.

TYPE: Infographic — vertical list overview card
ASPECT: 3:4 portrait (vertical), 2k quality

## Core Principles

- Clean composition with generous white space (about 40%). Simple background.
- Hand-drawn quality throughout — diagram-style visuals ONLY, NO realistic or photographic elements.
- Color values and color names are rendering guidance only — do NOT display color names, hex codes, or palette labels as visible text in the image.

## Text Style (CRITICAL)

- ALL text MUST be hand-drawn hand-lettered style, large and prominent. NO computer-generated fonts.

## Language

- All text in Simplified Chinese, except the brand name "Xpert" which must be spelled exactly as "Xpert" in Latin letters.

## Palette (notion, default)

- Background: pure white / off-white
- Ink: black and dark gray for ALL lines, text, arrows, doodles
- Accents: light pastel blue, light pastel yellow, light pastel pink rounded rectangles only (never render color names or codes as text)
- Style: simple line doodles with slight hand-drawn wobble, small stick figures, single-weight ink lines, clean uncluttered notion knowledge-card look

## Layout (List)

- Title at top, five rounded rows below, evenly spaced vertical list
- Nothing critical in the bottom 10% zone or top-right corner

## Content (LABELS — render ONLY these six text elements, nothing else)

1. Title at top, bold, centered: 「5个坑，一次说清」
2. Row 1 with a hand-drawn number badge 「1」: 「资料填实」
3. Row 2 with a hand-drawn number badge 「2」: 「看清投入」
4. Row 3 with a hand-drawn number badge 「3」, slightly larger and highlighted: 「认真是及格线」
5. Row 4 with a hand-drawn number badge 「4」: 「先沟通复盘」
6. Row 5 with a hand-drawn number badge 「5」: 「顺手迭代自己」

## Visual Concept

- Each row is a soft pastel rounded rectangle (alternate pastel blue / yellow / pink)
- A small hand-drawn icon next to each row: a document, an hourglass, a mountain with a flag, two speech bubbles, a small rocket
- Same series style as an all-white notion knowledge card

## Absolute Prohibitions

- Render ONLY the exact text listed above — absolutely NO other characters, letters, numbers, symbols, watermarks, color codes, or gibberish text anywhere
- NO currency symbols, NO money amounts, NO QR codes, NO logos, NO URLs
- NO recruitment wording such as 报名, 加群, 私信
- Do not distort or drop any Chinese character
