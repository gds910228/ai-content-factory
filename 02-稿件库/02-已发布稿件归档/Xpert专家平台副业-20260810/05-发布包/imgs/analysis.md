# 内容分析

## 内容类型与钩子

- **类型**：个人真实经历分享（AI 项目参与 5 个月 · 20 多期任务），带轻知识密度（Agent 能力边界、专业反馈的价值）
- **钩子潜力**：中高 —— "5个月/20多期"是经历厚度钩子；"用人的思考方式教AI回答问题"是认知钩子；❌✅适合人群是决策钩子
- **受众**：AI/技术同频人、想参与真实 AI 项目的人、对 Agent 能力边界好奇的人
- **互动信号**：结尾开放式提问（怎么判断模型真实水平）引导评论区讨论

## 滑动流（swipe flow）

封面定调（真实经历，非广告）→ 日常解释（建立可信度）→ 收获清单（价值锚点）→ 人群对比+提问（决策与互动）。情绪曲线：好奇 → 理解 → 认同 → 行动。

## 约束（来自活动质检返修）

- 零项目敏感信息：不出现项目名、机构名、内部机制、人名、群名、二维码
- 无金额数字、无利益导向表达
- 品牌名统一写作 **Xpert**
- 图文原创（纯文字卡 = 原创设计，无平台截图）
