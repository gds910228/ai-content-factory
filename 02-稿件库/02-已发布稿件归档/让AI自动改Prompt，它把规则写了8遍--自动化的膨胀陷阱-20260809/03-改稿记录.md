# 让AI自动改Prompt，它把规则写了8遍--自动化的膨胀陷阱 - 改稿记录

## 第1轮：结构逻辑优化

**问题诊断**：
- 第一章"它只有一个动作：读到 badcase，生成一段新规则，找个位置塞进去"与第二章"现实路径就三步：读 badcase 描述，生成一段新规则，找个它觉得相关的位置插进去"是同一组三步的重复，机制细节归属不清。
- 第二章到第三章缺少过渡，从"结构短板定调"直接跳到"四阶段表"，读者衔接略突兀。

**改动**：
1. 第一章删除三步枚举，改为情绪定调"它勤勉得可怕，唯一的本能就是追加"，把机制三步的所有权完整交给第二章。
2. 第二章开头补过渡设问"说它只会追加，具体是怎么个追加法？"，承接第一章的"追加本能"，引出决策树对照。
3. 第三章开头补过渡"机制讲完了，光说可能没感觉。我用自己那份开发提示词的膨胀过程，给你看它具体怎么一步步长胖的"，连接机制与量化证据。

**效果**：六章逻辑链理顺为 故事现象 -> 根因定调 -> 机制拆解 -> 量化证据 -> 治疗 -> 普适 -> 升华，无冗余，过渡自然。

## 第2轮：内容深度优化

**问题诊断**：
- 开头"发现"瞬间偏概括（"我后来回头读那份开发提示词时发现的"），缺阅读时的感官细节。
- 第一章"静音"缺"每次一小段"的具体触感，膨胀的隐蔽性说服力不足。
- 第四章"治不好"用第二人称"你换更新的模型"，不如第一人称可信。

**改动**（均在访谈事实范围内补质感，不杜撰新案例）：
1. 开头发现句改为"是我后来回头，把那份开发提示词从头到尾读了一遍才发现的：它从第一阶段到第四阶段，越写越长，越写越眼熟，到第四阶段，绕回了第一阶段的原点"，补"从头到尾读了一遍""越写越眼熟"的阅读触感。
2. 第一章静音句补"每次就加那么一小段"（源自访谈Q5"每次都是一小段"），让隐蔽性可感。
3. 第四章"你换更新的模型"改为第一人称"我换过更新的模型试，结果一样"，呼应前句"我试过，治不好"，增强亲历可信度。

**效果**：故事锚点更具画面感，根因与治疗段的个人印记更强，未引入访谈外素材。

## 第3轮：语言风格优化

**问题诊断**：
- 高频词"说实话、那种感觉怎么说呢、真正、比如"已自然使用，但缺"其实""换句话说"两个换角度高频词。
- 第五章"只会做加法不会做减法"金句后缺一句换角度阐释，读者对"为什么判断不了"的理解偏单薄。
- 对比句（不是X是Y）已在多处自然运用（不是又没成是发现、不是模型不够强是勤勉拆刹车、不是bug是结构短板、治标治本），无需强加。

**改动**：
1. 第五章开头补"其实"高频词："其实你做 RAG……"，软化语气、贴合口语化习惯。
2. 第五章"只会做加法，不会做减法"后补"换句话说，经验它替你存了，但哪些是重复的、该并掉的，它判断不了"，用"换句话说"换角度阐释，强化"判断不了"的根因（源自访谈Q7）。

**效果**：高频词覆盖更全，金句后补足换角度阐释，口语与书面比例维持约 4:6，无 AI 式生硬过渡。

## 第4轮：细节情感优化

**问题诊断**：
- 开头"破防"是全文情感高点，但缺"那种感觉怎么说呢？"感受比喻句式（系列③用了2处，本篇仅第三章1处），开篇情绪渲染不足。
- 比喻需与第三章"小工补墙"意象区隔，避免重复。

**改动**：
1. 开头"破防"后补感受比喻"那种感觉怎么说呢？就像你给扫地机器人设了自动清扫，它每天勤勤恳恳把垃圾从这头扫到那头，一个月下来屋子没干净，垃圾倒堆成了一座小山，它还觉得自己超额完成了任务。"意象选扫地机器人（区别于第三章小工补墙），精准呼应"勤勉得可怕却帮倒忙"的核心，并预告第一章"勤勉"定调。
2. 本文为观点/根因型，无 SOP 步骤（刹车配置已降级指针⑤），故不强制"小技巧"格式，避免生造步骤违反"100%来自访谈"铁律。

**效果**：开篇情绪张力拉满，感受比喻句式达2处（与③持平），两个比喻意象区隔不撞，全程画面感增强。

## 第5轮：最终定型

**AI 痕迹检测**（全通过）：
- 无首先/其次/最后/综上所述等模板过渡 ✓
- 无值得注意的是/令人震惊是等空洞修饰 ✓
- 无作为一个XX身份声明 ✓
- 无让我们一起空洞号召 ✓
- 排比均为自然枚举（比如×3、别怀疑X别怀疑Y），非机械整齐 ✓
- 全文无感叹号 ✓

**风格一致性检查**：
- 高频词：说实话(说句实话/说实话)、其实、那种感觉怎么说呢(2处)、真正、比如、换句话说 全覆盖 ✓
- 个人印记：我用/我把/我后来/我试过/我换过/我最想提醒 贯穿 ✓
- 对比句(不是X是Y)、感受比喻(扫地机器人/小工补墙)、数据句(四阶段表/400→1500/8处/2.75倍)分布合理 ✓
- 标点强约束(v1.2)：双引号0处用于强调(仅页脚「在看」角括号)、破折号0处(远低于1-2上限，均用逗号冒号替代) ✓

**防撞车终检**：
- ①模型不听话4原因：未展开，仅"我第一篇讲的恶性循环"一句带过 ✓
- ③分层重构5解法：未展开，仅"Prompt怎么分层重构"作前文引用 ✓
- ⑤自检清单7问+刹车4机制：刹车点名3例(行数预算/语义去重/单次追加上限)后明确"具体配置见自检清单，本篇不重复"，未教参数、未列7问 ✓

**最后一处微调**：第一章"每次diff都很小…每次就加那么一小段"双"每次"重复，改为"就加那么一小段"。
