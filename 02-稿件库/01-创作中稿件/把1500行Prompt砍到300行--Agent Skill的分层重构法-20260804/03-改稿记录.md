# 把1500行Prompt砍到300行--Agent Skill的分层重构法 - 改稿记录

## 第1轮：结构逻辑优化

**优化目标**：检查整体结构完整性、段落逻辑递进、章节衔接。

**具体改动**：
- 第四章开头补充"五步地图"：明确五个动作的顺序与各自解决的子问题（搭骨架定位置 -> 外置减负 -> 参考文件一致性 -> 关键规则首尾强化 -> 散文改表格），让读者进入干货段前先有全局预期，避免五个解法读成无序列表。

**未改动**：开头（故事引入+四层结构）、第二章代码->Prompt衔接、第三章痛点、第五章升华结构均已完整，保持不变。

**结构现状**：开头(引子) + 一(Flask排查) + 二(代码->Prompt衔接) + 三(Prompt痛点无从下手) + 四(五步分层重构法) + 五(技术债+边界反共识+收尾)。符合"问题->方案->升华"递进。

## 第2轮：内容深度优化

**优化目标**：补充具体场景、量化数据、可执行细节，增强说服力与可落地性。

**具体改动**：
- 第四章解法1 补量化效果：把"整个文件还短了一大截"改为"整份 Prompt 从上千行压到了三四百行"，给出前后行数对比，呼应源文"1500 砍到 300、甜区 300-500 行"的数据。
- 第四章解法5 把"表格优于散文"从说教改成示范：原散文示例后直接补一张两列小表（表类型 -> 工具），让读者亲眼看到散文到表格的改造效果，符合风格报告"案例必须具体、有对比"。

**未改动**：Flask SSE 排查场景（已具体）、PRD/DEV Prompt 痛点（已具体）、技术债 hotfix 类比（已具体）。

## 第3轮：语言风格优化

**优化目标**：贴合风格报告高频词、对比句、感受比喻句式，去除生硬过渡。

**具体改动**：
- 第三章痛点末尾补一处"那种感觉怎么说呢？就像……"感受比喻句（老水管该换却怕砸墙），把"僵住不敢动"的抽象感受具象化，与第一章电缆比喻形成前后呼应。

**风格自检**：
- 高频词：说句说实话、换句话说、我的做法是、我后来照这个排，均已自然嵌入。
- 对比句密度：不是代码写错而是结构太乱、靠的不是加规则而是分层重构、位置决定优先级而非重要性、精简不是乱删是分层、分层目的不是细是到位、真正该升级的不是AI而是Prompt——6处对比句，密度合理。
- 无"首先/其次/综上所述/值得注意的是"等 AI 模板化过渡。
- 个人印记：我的做法是、我愣是没想过、我后来照这个排，突出第一人称。

## 第4轮：细节情感优化

**优化目标**：补充"小技巧"实操细节格式、增强画面感与可执行性。

**具体改动**：
- 解法3（参考文件一致性）补"小技巧"：外置后先列禁止字段/必覆盖维度清单，拿清单逐条对模板，对不上改模板不改规则。
- 解法4（指令三明治）补"小技巧"：用"这条规则被违反会不会搞砸整件事"作筛选标准，挑出 2-3 条上三明治。

**效果**：五个解法现在每个都配一条"小技巧"，读者能截图带走具体动作，符合风格报告"实操步骤后加小技巧"与"能截图带走的干货"要求。
