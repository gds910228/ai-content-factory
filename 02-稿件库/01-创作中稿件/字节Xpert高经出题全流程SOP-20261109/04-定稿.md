# 字节Xpert高经出题全流程SOP：从注册到结算

> **本文档用途**：高经出题全流程操作手册，配合《出题提示词资料包》使用。提示词全文在付费资料包内，本文只展示结构与关键截图。
> **适用对象**：已具备行业纵深（金融/法律/医疗/软件等）、能通过简历学历认证、愿意配强模型当陪练的出题人。
> **一句话总览**：注册认证 → 申请入群领题 → 首轮出题 → （可选加固）→ 本地自测 → 提交 → 平台质检打分 → 不达标返修 → 返修后再测再交 → 达标/FDE兜底结算。全程人工只做判断和把关，其余交给模型流水线。
> **版本**：v1.0 · 2026-11-09 定稿。机制类信息（单价/激励/配额/期限）随期数变动，以当期群通知为准。

## ③ 首轮出题：一次成型，全靠提示词

**操作三步：**

1. 在 ZCode 打开本题的工作文件夹
2. 上传 5 样基础材料：《出题通用规则》《高经济价值任务说明文档》《高经济价值任务难度突破指南》+ L1/L2 职业截图
3. 粘贴首轮出题提示词（资料包含科技版/金融版两个行业模板，换行业字段即可复用）

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/05-首轮-03-提示词结构截图.png]]
*首轮提示词结构（全文见付费资料包）：身份与分类 → 总目标 → 执行流程 → 输出要求*

**核心心法一句话**：难度必须来自"材料里会让模型犯错的东西"，而不是题面提醒——题面每写一句"必须如何处理"，等于把对应考点的坑提前填平，模型踩不到坑，难度分就压不过线。

**总目标**：三项指标一次达标并留余量——SOTA 得分率 ≤ 45、执行轮数 ≥ 55、运行时间 > 45 分钟（平台线 50/50/40，内部留余量）。

**执行流程 7 步**（提示词内置，模型自动走）：选题（真实的、有人拍板的决定）→ 决策链/标答骨架/难点清单 → 生成附件（固定种子脚本、原始导出格式）→ 写题面（不透题）→ 交付物设计（6–8 份、跨文件对数、真跑要求）→ 重测与步数预算 → 考点/作答思路/标答（独立核算+闭环验证）。

**跑完后的产物形态**（对照检查，缺一样都不算完成）：

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/05-首轮-01-跑完后的工作目录.png]]
*工作目录实拍：根目录 upload_latest/ + v1/ + CHANGELOG.md；v1 内含题目-文字.md、考点.md、作答思路.md、标准答案-文字.md、附件/、标准答案附件/、生成脚本/、内部自检.md、表格信息.md*

- **每版本是完整一套**：题面、附件、考点、作答思路、标答（文字+附件）、合并的表格信息文档、内部自检——不能只放被改动的文件
- **upload_latest/ 只放推荐上传版**（不含内部自检），每次更新时重新生成

最后把要填表格的信息**合并成一份文档**（样例）：

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/05-首轮-02-合并表格信息文档样例.png]]
*合并文档样例首屏：任务名称、任务类型、任务形式、L1/L2 行业、L1/L2 职业、真实工作背景、题目-文字、考点（本例 58 条）、作答思路、标准答案-文字*

## ④ 可选加固：何时做，何时跳过

**决策标准**：

- **赶时间 / 冲一次合格**：跳过加固直接交。国庆实战：16 题省掉加固环节，8 题一次通过 + 2 题 FDE 兜底，两个半小时落袋一万六
- **时间充裕 / 新手前两期**：跑一轮加固提示词（资料包"返修提示词-加固分支"），30–50 分钟，目标提升时间/步数/难度，**不改任务本质**

加固提示词逻辑（引用结构，全文在付费包）：触发来源选"**加固**"——资料包返修提示词的【触发来源】二选一之一（另一种"评分"见⑤本地自测不达标与⑧平台打分不达标两个场景）→ 先体检（透题扫描/考点统计/难点落点/两种重测）→ 只改诊断出的缺口 → 版本管理照旧（vN 整体复制为 vN+1）。

## ⑤ 本地自测：双窗口协议（烟雾测试定位）

**定位先纠偏**：本地分**预测不了**平台分（实测案例：本地 73 分平台 44 分放行、本地 86 分平台 48.92 分一轮通过、本地 77 分平台 90.75 分打回）。自测的价值是**筛掉明显过易的题**，不是卡提交门槛——**3 次全对的考点删掉，其他直接交**。

**双窗口操作：**

**窗口一 · 答题**（新开会话，只传题面，不传标答）：

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/07-自测-01-答题窗口.png]]
*答题窗口：只上传题目 Prompt + 全部问题附件，标答/考点/作答思路一律不上传*

第一句话术："**忘掉上次解题过程和评分结论，不要查找记忆，请完成以下任务并交付全部文件。**"

**窗口二 · 评分**（另开新会话，传答卷+标答+考点+作答思路）：

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/07-自测-02-评分窗口.png]]
*评分窗口：答卷 + 标准答案（文字+附件）+ 考点 + 作答思路对照评分*

评分要求（资料包含完整评分提示词）：逐条打分、**数值落入容差才得分、状态/集合/字段完全一致才得分、部分正确 0 分**、每条给答卷原文证据，最后**自曝 3 条可能给松的考点并按严格口径重判**。

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/07-自测-03-评分输出样例.png]]
*评分输出样例：逐项得分/扣分说明 + 得分率汇总 + 偏松自曝与严格复判*

**自测协议**：同一版本跑 3 次取平均；记录**原始分 + 严格复判分**两个数；只改考点用旧答卷重判即可，改了题面/附件才重新作答。记录格式参考：

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/07-自测-04-三次分数记录表.png]]
*分数记录实拍：期数+题号 / 平台给分 / 本地三次分 / pass·异常值备注*

**判读标准（按严格复判分）**：

| 严格复判得分率 | 动作                             |
| ------- | ------------------------------ |
| ≤ 35%   | 保持不动，直接提交                      |
| 35%–60% | 局部改：先清题面透题，再改考点（资料包"自测后优化提示词"） |
| > 60%   | 强制重构权重，禁止只修补失分点                |

不达标就回到出题会话继续发起返修提示词（触发来源选"**评分**"，把模型给的评分与反馈粘进【自测情况】），按扣分项逐条修：

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/07-自测-05-本地自测评分不达标继续返修.png]]
*本地自测评分不达标 → 继续返修示例：在项目会话粘贴返修提示词，按评分反馈逐条修。至此返修提示词两种触发类型都有了演示——"加固"型见④，"评分"型见本图与⑧*

## ⑥ 首次提交：填表、传包、改状态

**提交三动作**（对应出题多维表格的列）：

1. **贴文字**：把合并文档里的内容对应贴进 prompt、考点 rubric、作答思路、标准答案-文本等列（逐条分点，不用表格）
2. **传压缩包**：两个附件栏各传一个压缩包——「输入附件」传题目附件.zip，「标准答案-附件」传标答附件.zip；内部自检**不进**上传包
3. **改状态**：全部字段填完后，把「题目是否完成」从"未完成"更新为"**已完成**"——**无需单独通知小组长**，表格状态就是提交通知

**激励规则**（各期略有差异，以当期群通知为准）。五期官方原话：

> 单题价格 1400 元/题；一次合格激励 200 元/题；高产激励：累计完成 5 题激励 100 元/题，累计完成 8 题激励 200 元/题。

四期曾有过早鸟（3 天内提交加 200 元），后续期数未见延续。历史各期单价在 1200–1800 元区间浮动，**速度和一次合格就是钱**。

## ⑦ 平台打分：读懂状态，别瞎动

**提交后盯两处**：飞书群 + 多维表格通知。字段遗漏、AI 率不通过、前三阶段不通过，都会通过**多维表格助手**推送给你；每一轮质检完成，字节老师会在群里发通知。

**机评机制**（为什么分数迟迟不出 / 什么算数）：

- 最终难度分由**机评 Rubrics** 打出：综合题面 + 考点 + 标答生成评分标准，作答思路仅弱辅助——所以标答必须写全关键数值，题面/考点/标答三者必须一致
- 难度分显示"**需要重跑**"或"**0**" = 模型回复被截断，质检自动重抓，**不要改题，等就行**
- 难度分出了但还没开返修权限：先在本地把修改做好，等【待返修】权限打开再粘贴进表格
- 三阶段通过后还有 GSB 评测

## ⑧ 指标不达标返修：先诊断分档，再动刀

**平台返修建议表**（质检官方口径）：

| 难度分         | 建议                             |
| ----------- | ------------------------------ |
| 50 < 分 < 65 | 重点改考点：赋权、删送分考点、原子化拆分           |
| ≥ 65        | 整体修改：考点 + prompt + 附件全动，按层分步验证 |
| 达标但步数/时长不足  | 只加有效工作量：原始导出、逐条明细、真跑求解、跨文件对数   |

**资料包"返修提示词"四档诊断**（引用结构，全文在付费包）：档1 清透题→改考点；档2 整体重构按层验证；档3 只加工作量；档4 只补短板，其他不动。**不为改而改**——诊断结论是"没有合理加固空间"就不建新版本。

**返修期限：一般 3 天**，留意飞书群通知，超期题就废了。

**返修提交**：在**原记录**上更新——返修说明写清改了什么、为什么改，替换更新后的字段内容和附件，不新建记录：

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/10-返修-01-返修提交操作.png]]
*返修提交：在原题目记录里补充返修说明、更新字段，红字标注为填写要求*

**返修意见当宝贝**：质检老师的具体意见是平台免费的校准信号，逐条回灌进提示词——四期每题返修 3 遍，到五期一次通过 6 题，中间就是提示词吃掉了所有返修教训。同一个坑，平台只教你一遍。

## ⑩ 达标结算与 FDE 兜底：落袋的才是钱

**三条出路：**

1. **高经达标**：按当期单价结算（历史期 1200–1800 元/题）+ 激励（一次合格 200/题、高产 5 题+100/题、8 题+200/题，以当期通知为准）
2. **FDE 兜底**：验难过不了高经线 ≠ 白做。官方通知原文：

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/11-结算-01-FDE分流群通知.png]]
*FDE 分流官方通知：达标状态、返修选择权、结算规则全说明*

> - FDE 是另一个项目，难度要求比高经济低一些
> - 难度符合要求的题目状态会显示【已通过，符合FDE结算标准】
> - 可以继续返修冲高经价；不想返修可直接放弃返修、按 FDE 价格结算
> - 符合 FDE 标准的题**无论是否返修、返修后是否合格都会结算**；返修后满足高经难度就按高经标准结算
> - 代价：FDE 档不享受一次通过、高产大户等奖励

   FDE 结算金额 **600–1000 元**（按题目难度区分度对应不同档位）。

3. **兜底也够不着**：一分没有（验难返修 2 次上限后作废，不建议再修，可返修后投下一期）

**结算确认**：出结算表后，核对 expert ID 和金额，在「是否确认」列回复"是"。表里能看到题目难度、单价、早鸟激励、最终结算金额：

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/11-结算-02-结算确认操作.png]]
*结算确认表：核对 expert ID 与金额后，"是否确认"回复"是"*

![[02-稿件库/01-创作中稿件/字节Xpert高经出题全流程SOP-20261109/assets/11-结算-03-提现路径.png]]

**结算周期要有心理预期**：高经四期中秋（9/23）发布任务，**十月底**才有第一轮质检结果；五期国庆发布，**十一月初**出第一轮结果。近期六/七/八/九期 1–2 周就发一期，节奏加密，但质检和结算依然慢——**管线不是存款，落袋的才是钱**。自己维护一张题目编号跟踪表（已确认到账/未确认），心里有数。

## 附录C · 风险与劝退清单
