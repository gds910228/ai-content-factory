## ③ 首轮出题：一次成型，全靠提示词

**操作三步**：
1. 在 ZCode 打开本题工作文件夹
2. 上传 5 样材料：《出题通用规则》《高经济价值任务说明文档》《高经济价值任务难度突破指南》+ L1/L2 职业截图
3. 粘贴首轮出题提示词（资料包内含科技版 / 金融版两个行业模板，换行业字段即可复用）

**提示词结构（全量版见付费包，此处只看骨架）**：
【待补图：05-首轮-03-提示词结构截图.png】
- 【我的身份与分类】：行业/职业 + 已做选题规避清单（防查重）
- 【总目标】：一次达标并留余量——SOTA 得分率 ≤ 45、轮数 ≥ 55、时长 > 45
- 【执行流程】7 步：选题（真实拍板决定）→ 决策链/标答骨架/难点清单 → 生成附件 → 写题面（不透题）→ 交付物设计（6–8 份、跨文件对数）→ 重测与步数预算 → 考点/作答思路/标答
- 【输出要求】：产物写入 v1/、建 CHANGELOG.md、结构自评（不预估得分）

**核心心法**（一句话版）：难度必须来自"材料里会让模型犯错的东西"，而不是题面提醒——题面每写一句"必须如何处理"，等于把对应考点的坑提前填平。

- 每版本完整一套：题面、附件、考点、作答思路、标答（文字+附件）、合并的表格信息文档、内部自检

## ④ 可选加固：何时做，何时跳过

**决策标准**：
- 赶早鸟（任务发布次日 24 点前提交合格有激励）→ **跳过加固直接交**，国庆实战：16 题省掉加固，8 题一次通过 + 2 题 FDE 兜底
- 时间充裕 / 前几期返修率高的新手 → 跑一轮加固提示词（资料包"返修提示词-加固分支"），30–50 分钟，目标提升时间/步数/难度，不改任务本质

**提示词要点**（引用结构，全量在付费包）：触发来源选"加固"→ 先体检（透题扫描/考点统计/难点落点/重测）→ 只改诊断出的缺口 → 版本管理照旧。

## ⑤ 本地自测：双窗口协议（烟雾测试定位）

**定位纠偏**：本地分**预测不了**平台分（本地 73 分平台 44 分放行、本地 86 分平台 48.92 分的案例都有）。自测的价值是**筛掉明显过易的题**，不是卡提交门槛——3 次全对的考点删掉，其他直接交。

**双窗口操作**：
1. **答题窗口**：GLM5.3-FLASH 新开会话，只传题目 Prompt + 全部问题附件（不上传标答/考点/作答思路），第一句："忘掉上次解题过程和评分结论，不要查找记忆，请完成以下任务并交付全部文件"
2. **评分窗口**：另开新会话（优先换模型），传题目 Prompt + 答卷交付文件 + 标答（文字+附件）+ 考点 + 作答思路，按评分提示词逐项打分，要求"数值落入容差才得分、状态集合字段完全一致、部分正确 0 分、给证据"，最后自曝 3 条偏松项并按严格口径重判

【待补图：07-自测-01-答题窗口.png】
【待补图：07-自测-02-评分窗口.png】
【待补图：07-自测-03-评分输出样例.png】
【待补图：07-自测-04-三次分数记录表.png】

**自测协议**：同版本跑 3 次取平均；记原始分 + 严格复判分两个数；只改考点用旧答卷重判即可，改了题面/附件才重新作答。

**判读标准（按严格复判分）**：≤35% 保持不动 / 35–60% 局部改 / >60% 强制重构（对应资料包"自测后优化提示词"）。

## ⑦ 平台打分：读懂状态，别瞎动

**质检漏斗**【复用：质检流程.jpg】：
```
专家出题 → 三阶段质检 ─不通过→ 返修（不占次数）→ 回三阶段质检；截止仍不过→作废（可修后投下一期）
              ↓通过
          题目验难 ─不通过→ 返修（占次数，最多2次）→ 回三阶段质检；2次仍不过→作废（不建议再修）
              ↓通过
            结算
```

**机评机制**（为什么分数迟迟不出 / 什么算数）：
- 最终难度分由**机评 Rubrics** 打出：综合题面+考点+标答生成评分标准，作答思路仅弱辅助——所以标答必须写全关键数值，题面/考点/标答三者一致
- 难度分显示"需要重跑"或"0"= 模型回复被截断，质检自动重抓，**不要改题**，等待
- 难度分出了但质检流程未结束：先本地改好，等【待返修】权限打开再粘贴，并告知小组长
- 三阶段通过后还有 GSB 评测

**打分结果长这样**【复用：高经五期打分截图（打码竖排水印）】：维表含 前三阶段状态 / 难度分数 / 运行时间（秒）/ 运行步数 / 题目通过状态（"已通过""已通过，符合FDE结算标准"）。

## ⑧ 指标不达标返修：先诊断分档，再动刀

**平台返修建议表**【复用：质检流程及返修思路.docx】：
| 难度分 | 建议 |
|---|---|
| 50 < 分 < 65 | 重点改考点（赋权、删送分、原子化） |
| ≥ 65 | 整体修改（考点 + prompt + 附件全动） |
| 达标但步数/时长不足 | 只加有效工作量（原始导出/逐条明细/真跑/对数） |

**资料包"返修提示词"四档诊断**（引用结构，全量在付费包）：档1 清透题→改考点；档2 整体重构按层验证；档3 只加工作量；档4 只补短板。不为改而改——"已经没有合理加固空间"就不建新版本。

**返修意见当宝贝**：质检老师的具体意见是平台免费给的校准信号，逐条回灌进提示词（四期每题返修 3 遍 → 五期一次通过 6 题，中间就是提示词吃掉了所有返修教训）。

## ⑩ 达标结算与 FDE 兜底：落袋的才是钱

**三条出路**：
1. **高经达标**：按 1200/1500/1800 三档结算 + 0–200 激励
2. **FDE 兜底**：验难过不了高经线 ≠ 白做——状态显示【已通过，符合FDE结算标准】即可按 FDE 价直接落袋；也可继续返修冲高经价。代价：FDE 档不吃一次合格/高产大户激励
3. **兜底也够不着**：一分没有（返修 2 次上限后作废，不建议再修）
