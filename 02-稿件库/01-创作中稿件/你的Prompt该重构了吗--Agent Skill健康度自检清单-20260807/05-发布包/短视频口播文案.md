## 口播文案（约80秒｜6段式）

**【0-3秒｜强钩子】**

（画面：近景，正对镜头）
（情绪：认真，带点无奈）

AI 连修三次都没改对，
（停顿0.5秒）
不是它笨，
（重音）是你的 Prompt 病了。

**【3-15秒｜痛点共鸣】**

（画面：切中景）

你也是这样吧？
AI 一出错，就加一条规则。
漏字段加一条，
选错工具再加一条。
越加越长，越加越乱。
（停顿0.5秒）
可你连它哪儿病了，
都说不清。

**【15-28秒｜破防转折】**

（情绪：恍然大悟，语速放慢）

我以前也这样，
后来想明白了：就图省事。
（重音）可你写下来了，
不等于它被听见了。
你以为说了的，
（停顿）可能根本没被听到。

**【28-60秒｜核心干货】**

（画面：切近景，配合手势数数）

教你三招，
给自己的 Prompt 把脉。

第一招，数行数，
过五百就危险。
（小声）自己读到哪儿走神，
模型就在那儿读不动。

第二招，搜禁令词，
严禁、必须、不得，
同一个意思出现三次，
就是架构坏了。

第三招，跑最近的错案，
找它（重音）合理地做错的那次，
背后一定藏着打架的规则。

**【60-72秒｜认知升华】**

（画面：切中景，语气真诚）

记住一句话：
表达不等于遵循，
中间隔着三层损耗。
别再加规则了，
先给它把个脉。

**【72-80秒｜互动引导】**

（画面：切近景，指向镜头）

你的 Prompt 现在多少行？
评论区告诉我。
（停顿0.5秒）
关注我，
下篇拆自动化的坑。

## 封面图设计建议

- **尺寸**：1080×1920px（9:16 竖版）
- **主视觉**：人物半身口播姿态（侧身指屏幕），背景一份标注"1500行"的 Prompt 文档，文档上贴一张"处方单/听诊器"图形
- **封面大字**：别再加规则了（顶部大字，反共识冲击）
- **封面副字**：先给 Prompt 把个脉（中部）
- **角标**：左下角"7问自检清单"小标签（暗示收藏价值）
- **色调**：蓝灰冷色为主，"病了""别再加"用警示橙红强调
- **系列标识**：右上角小标"Prompt 系列 ⑤"

## 拍摄节奏建议

| 时段 | 内容 | 镜头 | 节奏要点 |
|---|---|---|---|
| 0-3s | 强钩子"病了" | 近景正对镜头 | 语速正常，"病了"前停顿制造悬念 |
| 3-15s | 痛点共鸣"你也是这样吧" | 中景 | 像跟朋友聊天，带共鸣感，不要说教 |
| 15-28s | 破防转折"图省事" | 中景 | 语速放慢，"可能根本没被听到"压低声音 |
| 28-60s | 三招干货 | 近景+手势 | 手势数一二三，节奏明快，每招间微停顿 |
| 60-72s | 认知升华"表达不等于遵循" | 中景 | 真诚语气，金句放慢，留白让用户截图 |
| 72-80s | 互动引导 | 近景指镜头 | 指镜头动作，结尾干脆不拖 |

> **拍摄提示**：全程一人出镜口播即可，无需复杂场景变换；三招干货段可在画面侧边同步弹出文字要点（严禁/必须/不得、三次、合理做错），增强收藏感。
