# 你的Prompt该重构了吗--Agent Skill健康度自检清单 - 改稿记录

## 第1轮：结构逻辑优化
- **澄清第0问框架**：原文"7个问题…但在7问之前还有个第0问"易让读者困惑是7问还是8问。改为"先卡一道前置关…卡过这一关，再进后面7问做诊断"，明确第0问是入口信号、7问才是诊断。
- **补第5->第6问过渡**：第6问开头加"光把参考内容外置还不够"，承接第5问的"外置"动作，引出第6问的"一致性"。
- **补第6->第7问过渡**：第7问开头加"前面6问都是你手动能查的，最后这一问专门留给用工具自动改Prompt的人"，区分手动诊断与自动化场景。
- 结构完整性确认：开头(场景+痛点)10% + 正文(7问+心智)75% + 结尾(行动号召)15%，比例合规，无冗余章节。

## 第2轮：内容深度优化
- **DEV场景补情绪**：连修三次后加"那一刻真有点想摔键盘"，用风格高频情绪词增强代入感。
- **第1问补效率对比数据**：开方后补"我自己有一份反复用的PRD提示词，从上千行压到300多行，最关键的几条禁令遵循率反而上来了"，落实访谈记录素材引用的300vs1500遵循率对比，给"少即是多"配硬数据。
- **第6问补个人感受**：审计发现矛盾后补"这种矛盾我自己查了半天才注意到，那一刻真有点后背发凉"，强化隐蔽坑的警示感。
- 案例场景确认：DEV场景已有项目(客户后台)、功能(入参校验/边界)、后果(凭空枚举值)，本轮补齐情绪层。

## 第3轮：语言风格优化
- **补高频词"其实""换句话说"**：二节"图省事"改为"其实就图一个省事"；"你做的只是表达了一条规则…不是让这条规则真正生效"后补"换句话说，你写下来了，不等于它被听见了"，强化表达≠生效的对比。
- 金句密度复检：全文约8句金句、约每375字1句，达标；无"首先/其次/综上"等AI式过渡；口语化/书面化比例约4:6，合规。
- 对比句复检：不是它笨是…病了、不是更累是第一次真在解决问题、不是强调够是架构坏了、不是加规则是先诊断，对比句分布合理。

## 第4轮：细节情感优化
- **DEV场景补时间细节**："直到有一次"改为"直到前阵子"，增强真实感（不与系列①的"2025年9月"时间线冲突）。
- **第2问补小技巧**：禁令集中后加"按违反了会出事的严重程度排，最严重的压在第一行"，给位置优化配增值实操。
- **第4问补小技巧**：Ctrl+F搜词后加"连同同义说法一起搜…否则漏掉换皮重复规则"，补搜禁令词的实操细节。
- 感受比喻复检：老水管比喻(痛点)+号脉开方比喻(结尾)各1处，适度不追加；情绪词"想摔键盘""后背发凉""咯噔"分布关键位置。

## 第5轮：最终定型（写入 04-定稿.md）
- **AI痕迹终检**：无"首先/其次/综上/作为一个XX/让我们一起"等模板化表达；无"值得注意的是/令人震惊的是"；第6问"一个惊人的问题"改为"一个特别隐蔽的问题"（去模板感、更精确）。
- **排比检测**："你说出来的未必被听到；被听到的未必被遵循；被遵循的未必没跟别的规则打架"为顶真式金句（修辞手法），非AI模板化排比，保留。
- **标点强约束复检**：全文双引号零误用（未给任何普通词加重点，禁令词严禁/必须/不得一律顿号列举）；破折号0处（远低于1-2处上限，跨篇引用《》中的--为被引文章原标题、非本文破折号）。
- **风格一致性**：高频词(说句实话×2/其实/换句话说)、个人印记(我现在的习惯/我自己有一份/我以前也这样/我精简Skill后)、对比句、感受比喻、小技巧(×3)分布合理，语气全程真诚不说教。
