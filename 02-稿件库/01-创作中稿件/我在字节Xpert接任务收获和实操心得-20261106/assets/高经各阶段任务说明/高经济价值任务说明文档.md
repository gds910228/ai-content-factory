

### 一、任务目标

项目背景：面向各行业专业人士收集来自真实工作中处理的任务和资料，题库用于测试Agent完成真实高价值办公工作的能力上限。​ 高经济价值是指专业人士在真实工作中会投入较多时间、调用多种材料或工具，且结果会被实际用于决策、执行、正式交付、合规流程或持续运营的任务。一个简单的判断问题是：如果豆包帮你完成了这个任务，你是否愿意为豆包支付100元​，**合格题目需要同时满足：**

1. 题目要素完备（提示词、附件、标答、考点等信息完备且符合规范）

2. 题目足够困难（分数必须满足，轮数、时间二选一即为达标）

|               |                                     |                                                                                                                                                                                                                                  |
| ------------- | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **指标**        | **量化要求**                            | **你可以这么做**                                                                                                                                                                                                                       |
| Sota模型得分率（必中） | <= 45 分                             | 1. 在真实场景中挖掘模型很难满足的需求，构造场景对模型反而简单<br>  <br>2. 进一步增加附件的数量和复杂程度，但您提供的附件必须与提示词相关<br>  <br>3. 把切片式任务环节变成一个完整的任务体系，考察模型闭环整体交付的能力<br>  <br><br>> 补充知识：一个执行轮次的边界就是一次完整的模型决策输出，也就是模型生成的 assistant message 条数，一轮里有≧1次LLM调用 和 ≧0次工具调用（了解就行） |
| Sota模型执行轮数    | > =55 步                             |                                                                                                                                                                                                                                  |
| Sota模型运行时间    | > 45 分钟 |                                                                                                                                                                                                                                  |

友情提示：本任务会查重，如发现题目与其他任务（无论是进行中的任务还是已结束的任务）中的题目相似度高题目按作废处理，是否相似以项目组判断为准，千万别拿其他项目的agent题目重复提交！

### 二、出题交付物（详见出题多维表格）

| 字段                      | 需要写清楚                                                                         |
| ----------------------- | ----------------------------------------------------------------------------- |
| **任务名称**                | 用真实工作名称概括，不写成抽象能力标签（简单的一句话概括这个任务要做什么）                                         |
| **任务类型**                | 选择最主要的一类；以最终用途和交付为准                                                           |
| **任务形式**                | 单轮或多轮，多轮需说明真实的承接关系                                                            |
| **L1行业**                | 按任务发生组织的主营业务，从行业配额表的L1行业中单选                                                   |
| **L2行业**                | 从对应L1行业下的L2行业中单选                                                              |
| **L1职业**                | 按主要负责最终交付的人，从职业分类树的“职业簇”中单选                                                   |
| **L2职业**                | 填写实际执行任务的具体岗位，使用职业分类树“典型职业”的颗粒度；以职责和工作流为准                                     |
| **真实工作背景**              | 为什么现在要做、处于哪个项目或业务环节、有哪些硬约束                                                    |
| **题目-文字**               | 题目表述在尽量真实的前提下应当没有歧义，清晰给出需要作答的内容和需要交付的产物                                       |
| **题目-附件**<br><br><br>   | 提供完成任务所需的真实或仿真材料，例如文档、表格、访谈记录、项目资料、业务数据、参考模板等。附件之间应服务于同一个复杂目标，不能只是多个无关材料的简单拼合 |
| **考点**                  | 给出关键评分点、通过标准、枚举易错点、枚举正确答案                                                     |
| **作答思路**<br><br><br>    | 描述专家认为合理的完成路径，包括应如何拆解任务、使用哪些资料、关键判断点在哪里、容易出错的地方是什么                            |
| **标准答案-文字**<br><br><br> | 如果题目有明确答案，给出完整标准答案或关键结论。如果题目偏开放，给出高质量参考答案，并说明它为什么好，包括结构、内容、判断质量、可执行性等。        |
| **标准答案-附件**<br><br><br> | 提供标准答案对应的附件，例如最终报告、整理后的表格、评分样例、参考文件、可视化结果、交付物模板等，附件应与题目要求一一对应                 |

4. #### 高经济价值说明

本项目需要具有高经济价值的任务：

* 是真实的专业工作：来自实际工作流程，有具体背景和约束；可以脱敏，但不能只用一个专业角色包装通用问答。

* 结果有明确用途：能说清谁会使用、拿去做什么，以及完成后会触发什么决策、执行或交付。

* 不能靠一次搜索或普通回答完成：需要处理文件、数据、多来源信息、专业规则、工具或相互关联的多个步骤。

* 有强价值证据：专业人工通常需16小时以上；任务周期性发生并能持续节省时间；直接影响收入、成本、客户、交易或合规；做错会造成明显损失；已有直接付费、采购或真实使用证据。

* 任务复杂性：不能靠一次搜索或普通回答完成，需要处理复杂文件、数据、多来源信息、专业规则、工具等内容，或任务包含相互关联的多个步骤。

* 以下任务不纳入：
  
  | 不纳入的任务          | 判断方法                                    |
  | --------------- | --------------------------------------- |
  | 简单知识问答          | 主要考察“知不知道”，结果不会进入真实工作流程。                |
  | 单点事实、日期或定义查询    | 一次搜索即可完成；增加律师、医生或投资人角色，也不会自动变成高价值任务。    |
  | 单篇文章或单份材料摘要     | 只有信息压缩，没有形成比较、判断、决策或项目交付。               |
  | 普通润色、翻译、排版和简单制图 | 如果没有明确客户、会议、申报或业务用途，只是标准文档能力题。          |
  | 玩具代码和一次性小页面     | 没有真实系统、数据、使用者或后续研发动作。                   |
  | 靠扩大范围制造“长任务”    | 例如无边界地要求“调研全部资料”或“做成上百页”，但没有真实使用方式和优先级。 |
  | 多个互不相关的小任务拼接    | 各部分没有共同目标，也不存在真实的前后依赖。                  |
  | 缺少关键材料或权限       | 任务看起来真实，但当前信息不足以开始，或必须依赖未提供的私有环境与凭据。    |
