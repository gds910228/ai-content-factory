## 为什么你需要一个“AI 情报员”？

在这个信息爆炸的时代，我们面临的最大痛点不是“找不到信息”，而是 **“如何从噪声中提取信号”** 。

试想一下你现在的早晨：

1. 打开 36氪、虎嗅、掘金、开源中国等 5-6 个网站。
2. 快速浏览上百条标题，试图找出与"AI"、"大模型"相关的内容。
3. 复制链接，粘贴到文档，再手动写摘要。
4. 转发到公司群或自己的知识库。

这一套流程下来，至少耗费 40-60 分钟。而且，一旦忙起来忘记看，就会产生严重的 FOMO（错失恐惧症）。

**如果有更优雅的解法呢？** 比如，当你还在睡梦中时，一个不知疲倦的机器人已经帮你跑完了所有网站，筛选出你最关心的硬核干货，用 AI 提炼成精简日报，并在早晨 8 点准时推送到你的飞书手机端。

## 实战复盘：产品经理阿强的高效进化史

为了让你更直观地理解这套系统的威力，我们来看一个真实的用户故事。

**解决过程** ： 阿强决定不再当“搬运工”。他利用周末时间，在本地部署了一套 **n8n自动化** 系统。

1. **数据源（Ears）** ：他配置了 RSS 节点，自动抓取主流科技媒体。
2. **过滤器（Brain）** ：他写了一段简单的 JavaScript，告诉系统：“我只关心‘生成式AI’、‘RAG’、‘DeepSeek’等关键词，其他的娱乐八卦统统过滤掉。”

网上很多 n8n 教程参差不齐，坑多填少。本教程基于 Windows 环境，采用最稳定的 Docker 部署方案，确保你一次跑通。（具体详细图文教程获取方式请看文末）

### 第一阶段：地基建设（Docker 环境准备）

n8n 是一个基于节点的工作流自动化工具，本地部署最安全、免费。

1. **系统自检** ：按 `Win + R` 输入 `winver` 。如果是家庭版 Windows，建议升级到专业版，或者手动开启 Hyper-V。
2. **开启虚拟化** ：在“启用或关闭 Windows 功能”中，勾选 **Hyper-V** 和 **虚拟机平台** ，重启电脑。
3. **安装 Docker** ：去 Docker 官网 下载并安装。
- *避坑指南* ：注册和拉取镜像时由于网络原因可能受阻，建议配置国内镜像源（如阿里云、网易等）。
	- *换源操作* ：在 Docker Engine 设置中，粘贴如下配置并重启 Docker：
5. **启动 n8n** ： 打开 CMD 命令行，输入以下指令拉取并启动 n8n：
	```
	docker volume create n8n_data
	docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
	```
	成功后，浏览器访问 `http://localhost:5678` ，注册账号即可进入 n8n 界面。

### 第二阶段：工作流搭建（这里只列出最核心的五步法）

#### Step 1: 定时触发 (Schedule)

既然是日报，就要准时。

- 搜索节点： `Schedule`
- 设置：Trigger Interval 选 `Days` ，时间设为 `8` (早上8点)。

#### Step 2: 获取情报源 (RSS Read)

这是我们的“顺风耳”。

- 搜索节点： `RSS Read`
- 填入 URL：建议聚合多个源。
- 36Kr: `https://www.36kr.com/feed`
	- 虎嗅: `https://www.huxiu.com/rss/0.xml`
	- 掘金: `https://juejin.cn/rss`
	- 钛媒体：https://www.tmtpost.com/rss.xml
	- 开源中国：https://www.oschina.net/news/rss

#### Step 3: 智能筛选 (The Filter) —— 关键步骤

RSS 的内容太杂，我们需要用代码进行关键词清洗。

- 搜索节点： `Code`
- **代码抄作业** （将文末文档中代码粘贴进去，筛选 AI/科技或者你想要筛选内容的相关关键词）

#### Step 4: AI 提炼与总结 (Zhipu AI)

这是工作流的“大脑”。我们使用国产优秀的 **智谱GLM** 模型（API 便宜且强大）。

- **准备工作** ：注册 智谱AI开放平台，获取 API Key。
- **构建请求** ：先用一个 `Code` 节点构建 Prompt，告诉 AI：“你是一个科技编辑，请从输入数据中挑选 10 条最重要的新闻，并生成 Markdown 格式日报。”
- **发送请求** ：使用 `HTTP Request` 节点。
- Method: `POST`
	- URL: `https://open.bigmodel.cn/api/paas/v4/chat/completions`
	- Body: 引用上一步构建好的 JSON。

#### Step 5: 飞书机器人推送 (Feishu Bot)

最后一步，将 AI 吐出的内容发送到你的手机。

1. **飞书开发者后台** ：创建企业自建应用，获取 App ID 和 App Secret。
2. **开通权限** ：开启“机器人”能力。
3. **配置 n8n** ：
- 使用 `Code` 节点将 AI 的 Markdown 回复封装成飞书卡片格式（JSON）。
	- 使用 `Message:send message` 节点（需安装社区插件 `n8n-nodes-feishu-lite` 或直接用 HTTP Request 调用飞书 Webhook）。
	- **避坑** ：获取 `Chat ID` 时，利用飞书 API 调试台最快。

## 优缺点分析

在这一整套 **n8n自动化** 搭建过程中，我总结了它的核心优劣势，供你参考：

| 维度 | 优势 (Pros) | 劣势 (Cons) |
| --- | --- | --- |
| **成本** | **极低**  Docker 本地部署免费，智谱 API 每日有免费额度或极低费率。 | 需要一台电脑保持开机运行 Docker，或者购买云服务器（VPS）。 |
| **隐私** | **数据完全私有化**  所有流程跑在本地，不用担心公司敏感数据泄露给第三方平台。 | 相比 Zapier 等云端 SaaS，没有现成的云端环境，需自己维护。 |
| **灵活性** | **无限扩展**  支持 1000+ 应用，不仅能做新闻日报，还能做竞品监控、自动回复等。 | **上手门槛略高**  虽然是低代码，但处理复杂逻辑时仍需懂一点 JavaScript 和 JSON。 |
