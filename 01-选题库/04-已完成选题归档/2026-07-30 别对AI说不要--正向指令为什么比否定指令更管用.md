## 一、选题核心背景与用户痛点

几乎每个初级开发者写 Prompt 都习惯用否定指令："不要给建议""不要展示这个字段""不要遗漏维度"。但模型偏偏就给了建议、展示了字段--**越禁越来**。这是 Prompt 里最普遍却最被忽视的反模式。

根因是 token 生成本质是**正向选择**--选择下一个最可能的 token。否定指令只微弱降低不想要 token 的概率，正向指令才主动提升期望输出的概率。再加上"粉红大象效应"：越说"别想"越激活那个概念。所以你越写"严禁"，模型越需要先"激活"被禁内容。本选题用最普适的反模式切入，受众几乎覆盖所有写 Prompt 的人。

## 二、选题核心切入角度（3个以上）

1. **反直觉原理**：为什么"不要做 X"遵循率显著低于"只做 Y"--从 token 生成的正向选择机制解释否定指令的低效本质，配多项研究结论支撑。
2. **粉红大象效应**：越说"禁止"反而提高被禁内容出现概率（心理学类比 + LLM 机制），解释"为什么禁了字段照样输出"这一高频困惑。
3. **实操改造**：把一列"严禁"改造成"场景 -> ✅正向行为 -> 对应禁止项"三列表格，正向行为占更多篇幅放前面，禁止项退为简短补充。模型读到时注意力首先落在"该做什么"上。
4. **训练偏差本能**：模型倾向输出"建议"、倾向关联相关概念（如归因失败↔ID映射）、倾向"有用"多给信息--这些本能会和你的否定指令对着干，需用正向指令对冲。
