## 一、选题核心背景与用户痛点

**背景**：本周两份大厂内部实录独立收敛到同一个判断。淘天（[[01-选题库/03-行业干货选题池/我对 AI Coding 的一点思考：从 Spec 驱动转向环境与验证驱动|从 Spec 驱动转向环境与验证驱动]]）提出投资分界线："下一代 SOTA 模型发布时，我正在做的事，是获益，还是作废？"——替代模型推理能力的投入（提示词技巧、流程编排）会被升级吸收；给模型提供它造不出的信息的投入（环境、验证）持续增值。腾讯（[[模型越来越强， harness该留下什么？|模型越来越强，harness该留下什么？]]）用实践给出同构答案：删掉 harness 61% 后发现，"凡是补模型能力缺口的都会过期"，而"信息源头在人的头脑里 → 永远是你的责任"。

**目标受众的核心痛点**：
1. **学习焦虑**："我熬夜背的提示词技巧、囤的教程，会不会下个版本一出就全白学了？"——这是初级开发者最普遍的隐忧。
2. **投入迷茫**：时间有限，到底该学 Prompt 工程、该学框架编排、还是该学别的？没人给过一条可操作的判断线。
3. **已有资产不知估值**：自己的 CLAUDE.md、skills、小工具箱，哪些是"越放越值钱的资产"，哪些是"等着被作废的负债"，从未盘点过。
4. **被贩卖焦虑裹挟**：营销号天天喊"再不学 X 就晚了"，缺一个冷静的估值框架来自行裁决。

> 一句话：把两家大厂的"技术资产估值模型"翻译成个人开发者能上手的自检清单——你的时间和积累，哪些在贬值区，哪些在增值区。

## 二、选题核心切入角度（3个以上）

1. **"一句话估值法"开场**：抛出淘天那个问题——"下一代模型发布时，你正在学/囤/写的这个东西，是获益还是作废？"让读者立刻拿自己手头的东西对号入座，制造代入感。
2. **贬值区清单（扎心盘点）**：提示词技巧库、分步流程指引、CRITICAL 强调语、prefill 类格式技巧、"教模型做事"的教程——用腾讯素材的铁证支撑：Anthropic 删掉自家系统提示词 80% 评测不掉、prefill 直接从 API 移除、"你以为在调风格，实际在削减召回"。
3. **增值区清单（方向指引）**：私有环境（你的构建/测试/部署脚本）、验证能力（什么算"做完"的标准）、只有你知道的业务上下文——"关于世界的信息不可能从权重里长出来"。
4. **【独家观点】"源头三问"自检法**：合并两篇的判据成一条个人版口诀——这信息的源头在公开语料里（会被内化，别囤）？在你自己的项目里（写成工具/linter，别写在指令里）？只在你脑子里（外化成文档，这是你唯一不可替代的资产）？
5. **与自家内容互证（知识补链）**：链接已发 [[02-稿件库/02-已发布稿件归档/AI工作流的护城河：你的Skills库才是真正的资产-20260606/04-定稿|Skills 护城河]]——"skills 库是个人开发者的增值区资产"这一判断现在有了两家大厂的独立背书，大厂与个人殊途同归。
