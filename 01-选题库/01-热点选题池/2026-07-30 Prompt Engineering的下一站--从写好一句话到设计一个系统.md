## 一、选题核心背景与用户痛点

认知痛点：很多人（尤其转行者）对 Prompt 的理解停留在"写好一句话""调几个技巧"，以为 Prompt 就是文字游戏。但随着 Agent/Skill 时代到来，单句技巧已不够--**指令位置、注意力分配、规则层级**成为关键。

痛点是认知滞后：还在用"加严禁"的老办法，没意识到 Prompt 已是一门系统工程。本选题做趋势观点输出，帮受众完成认知升级，契合账号"AI时代超级个体"与"实战派引路人"定位。作为系列的观点总纲，把前面几篇的零散技巧收束成一个完整主张。

## 二、选题核心切入角度（3个以上）

1. **认知升级主张**：Prompt Engineering 正从"写好一句话"进化为"设计一个系统"--指令位置、注意力分配、规则层级等工程化思维比反复加"严禁"有效得多。
2. **"少即是多"是物理定律不是鸡汤**：注意力机制有固定带宽，塞得越多每条指令分到的注意力越少；重复 5 遍看似强调，实则抢占其他规则的注意力配额；300 行版本遵循率优于 1500 行版本--因为每条规则终于有足够注意力去"读懂"。
3. **时代背景呼应**：Agent/Skill 爆发（Claude Skills、各类 Agent 平台），维护复杂系统 Prompt 成为常态，"系统化 Prompt 能力"正成为独立开发者的新基本功。
4. **给转行者的行动指引**：从"学技巧"转向"学系统"--掌握分层、注意力、一致性、防膨胀等工程思维，建立可维护的 Prompt 资产，而非堆砌一次性提示词。
