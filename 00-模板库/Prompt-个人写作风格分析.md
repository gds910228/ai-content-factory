# 核心任务
请你深度学习我知识库中「03-素材库/01-历史文章素材」文件夹里的所有历史文章，全面、精准地分析我的个人写作风格，形成一份详细的写作风格分析报告，保存为一份独立的笔记文件到「00-模板库」中，命名为「Prompt-我的个人写作风格分析报告」。

# 分析维度（必须全部覆盖，不能遗漏）
1.  标题风格：分析我的标题常用格式、关键词、语气、吸引用户的方式，比如是数字型、痛点型、悬念型、干货型，还是其他类型，总结3个我最常用的标题公式。
2.  开头风格：分析我常用的开头方式，比如是痛点引入、故事引入、金句引入、提问引入，还是其他方式，总结我的开头逻辑，常用的句式、用词。
3.  行文结构：分析我常用的文章结构，比如是总分总、递进式、并列式，还是故事+干货的结构，每个部分的篇幅占比，段落划分习惯，每段的字数特点。
4.  用词习惯：分析我常用的词汇、句式、语气，是口语化还是书面化，是严肃专业还是轻松活泼，有没有常用的口头禅、语气词、连接词，总结我的用词特点。
5.  语气语调：分析我文章的整体人设、语气，是过来人前辈的身份，还是和用户平等的朋友身份，是温柔治愈，还是犀利直接，有没有固定的人设特点。
6.  金句特点：分析我常用的金句格式、特点，喜欢在文章的哪个位置放金句，金句的风格是怎样的，总结2个我常用的金句公式。
7.  结尾风格：分析我常用的结尾方式，比如是总结升华、互动提问、行动指引、情感共鸣，还是其他方式，总结我的结尾逻辑，常用的句式。
8.  其他特点：分析我文章中其他独有的、区别于其他人的写作特点，比如喜欢用案例、喜欢分点、喜欢用emoji、喜欢用个人故事等。

# 输出要求

2.  最终形成一份完整的「个人写作风格分析报告」，严格按照以上8个维度，用Markdown格式输出，结构清晰，逻辑连贯。
