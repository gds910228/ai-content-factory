# Anthropic 开发者分享 Claude Code「理解验证」工作流

<body xmlns="http://www.w3.org/1999/xhtml">Anthropic 核心开发者分享了一套用于 Claude Code 的「理解验证」工作流。该工作流将 AI 定位为"高效且睿智的教师"，成功标准不仅是完成任务，更是确保人类对问题、方案及影响有可复述、可辩护的掌握。它通过增量教学、用户复述、清单+测验等方式，围绕问题域、方案域和语境域三条轴线展开，具体包含8个可执行步骤，强调在进入下一阶段前需确认用户已真正理解。此工作流旨在对抗长会话中人类易沦为"审批按钮"的"智能体黑箱"问题，强制沉淀决策上下文，实现可审计的深度理解。</body>
